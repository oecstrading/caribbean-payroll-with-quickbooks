OECS Time Clock for Windows
1. Unzip anywhere (e.g. Documents) and double-click "OECS Time Clock.exe".
2. Enter the activation code from Clock devices > Add tablet (pick the company and department/site).
3. Closing the window keeps the clock in the tray (bottom-right, near the time). Click the clock icon to open it.
4. It starts automatically with Windows. Right-click the tray icon to turn this off or quit.
