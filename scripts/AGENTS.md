# Scripts rules
- Generate versioned manual and brochure PDFs with scripts/generate-user-manual.py; serve from public/training via src/lib/training-resources.ts in both Training Hubs, independent of database availability. Preserve user uploads.
- The customer onboarding template is generated by scripts/generate-payroll-template.py into public/templates (currently v2). Keep its Payroll column names readable by src/lib/salary-sheet.ts, its Employees columns covering every employee-folder field (src/lib/onboarding-sheet.ts maps them), and its Company/Allowances/Loans/Accounts/Departments rows readable by the same module. The generator stores worked-out values beside the formulas; verify formulas on a copy in /tmp so LibreOffice does not erase those stored results from the shipped file.
